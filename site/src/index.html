    Where it works
    
        
    One engine, wherever you hand text to an AI.
    
        
    
          
    
            
    In the browser
    
            
    ChatGPT, Claude, Gemini, Copilot, Perplexity, DeepSeek and Le Chat. It checks what you type, paste, upload or drop, and holds the message until it knows it is safe.
    
            
    • Enter, the send button and form submits are all covered
    • Redact & send in one click, or review first
    • Replies that mention a placeholder can be copied with the real value
    
          
    
          
    
            
    In your coding agent
    
            
    Hooks for Claude Code check the prompt, the tool call, and what the tool printed. It uses the same rules as the dashboard's agent view.
    
            
    • A prompt with a key is blocked, with a safe version to send instead
    • Reading .env, ~/.ssh or any file that holds a key asks first
    • grep, cat and git diff output reaches the model redacted
    • Dangerous shell commands are denied
    
          
    
          
    
            
    In files and screenshots
    
            
    Text files, code, PDF, Word, Excel and PowerPoint are read on your device. Screenshots and photos are read with on-device OCR.
    
            
    • A screenshot of a .env is caught before it goes up
    • Offer a redacted text copy instead of the original
    • Anything it cannot read is said out loud, not skipped
    
          
    
          
    
            
    In the shell and in git
    
            
    The same check from the command line, so secrets stop at the commit too.
    
            
    python -m shadowlens.hook scan config.py
git diff --cached | python -m shadowlens.hook scan
python -m shadowlens.hook precommit
    
          
    
        
    
      
    
    
    

    
    
    
      
    
        
    How it works
    
        
    It sits between you and the send button.
    

        

        
      
          
    1. Check, quietly, as you type
      The composer is checked in the background, so a clean message is sent with no delay at all.
      2. 
          
    2. Hold what is risky
      Enter, the send button, a paste or an upload is held until the check finishes. A panel shows what was found as masks, never the value.
      3. 
          
    3. Swap, don't lose the context
      Redact & send replaces values with stable placeholders like [OPENAI_API_KEY_1]. The AI can still help with the shape of your problem.
      4. 
          
    4. Put the real value back, locally
      When the answer mentions a placeholder, it is highlighted and can be copied with the real value. The value never enters the page.

    What it catches
    
        
    Built to survive people (and attackers) who try to hide things.
    
        
    
          
    
            
      
              
    • OpenAI, Anthropic, AWS, GitHub, Slack, Stripe, Google, Hugging Face keys
    • Private keys
    • Database URLs
    • JWTs
    • Passwords next to their names
    • Random-looking tokens
    • Cards (Luhn)
    • Aadhaar (Verhoeff)
    • IBAN (mod-97)
    • SSN
    • PAN
    • Emails and phones
    • Internal hosts and private IPs
    • Confidential code markers
    • Hidden Unicode characters
    • Instructions aimed at the AI
      • 
            
    
            
    Cards, Aadhaar and IBANs are checked against their checksums, so random digits do not raise false alarms. Pick Disguised key above and watch it find a base64-encoded key.

    Trust
    
        
    A privacy tool that asks for as little as possible.
    
        
    
          
    No network
    The detection engine is a WebAssembly module inside the extension. It makes no requests. The only other place events can go is the optional dashboard on your own computer, over Chrome's Native Messaging.
    
          
    Small permissions
    It runs only on the seven AI chat sites. It does not ask for access to every website, your history or your tabs.
    
          
    Masks, never values
    History and the dashboard keep a site, a time, what happened, and masks like sk-p... (len 48) with keyed fingerprints. The text is never stored.
    
          
    A vault that forgets
    Real values behind placeholders live in memory for one tab. Close the tab and they are gone. They are never written to disk.
    
          
    Out of the page's reach
    The panel lives in a closed shadow root. The site's own scripts cannot read it, click it or switch the guard off.
    
          
    Held to a reference
    The Rust engine is checked against the Python reference by a conformance suite, a fuzzer that compared 70,000 random texts, and a benchmark with hostile inputs.
    
        
    

        
    
          
    Honest limits
    
          
      
            
    • It protects people who want to be protected. It cannot stop someone who turns it off, or an AI app it is not installed in (for example a phone app).
      • 
            
    • Detection is not a guarantee. A key written in a form nobody anticipated can slip through; that is what the allowlist, the fuzzer and bug reports are for.
      • 
            
    • Screenshots are read with OCR, which can misread characters. It is best effort and it says so.
      • 
            
    • Prompt-injection checks are heuristics: they flag the common tricks, not every possible one.
      • 
          
    
        
    
      
    
    
    

    
    
    
      
    
        
    For developers
    
        
    How it is built, and how it is kept honest.
    
        
    
          
    
            
      
              
    • Rust, as WebAssembly. A function-by-function port of the Python engine, with Python's regex semantics reproduced (\w, \b, ignore-case, even CPython's base64 and JSON behaviour).
      • 
              
    • Generated, not copied. Patterns and Unicode tables are generated from the Python reference; a test fails if they drift.
      • 
              
    • Conformance suite. 277 cases that any implementation must match exactly: findings, spans, masks, fingerprints, redacted text.
      • 
              
    • Differential fuzzing. Random texts built from fake secrets, disguises and awkward Unicode, compared byte for byte.
      • 
              
    • Fast on hostile input. Quadratic regexes were replaced with hand-written matchers; 64 KB of dots or a 200 KB base64 run takes milliseconds.
      • 
              
    • Tested in real Chromium against mock chats built on ProseMirror, Quill and plain textareas.
      • 
            
    
          
    
          
    
            
    
              Time to check hostile inputs, Rust against the Python reference
              
    InputRustPython

    Native build, on the development machine. The WebAssembly build the extension ships is slower (roughly 1.3 to 5 times on these inputs); a typical prompt still takes a few milliseconds once warm.
    
          
    
        
    
      
    
    
    

    
    
    
      
    
        
    Install
    
        
    From source, in about five minutes.
    
        
    
          
    
            1
            
    The browser extension
    
            
    Needs Node 20+ and Rust (for the engine).
    
            
    cd extension
npm install
node tools/build-engine.mjs
node tools/build.mjs
    
            
    Open chrome://extensions, turn on Developer mode, choose Load unpacked and pick extension/dist.
    
          
    
          
    
            2
            
    The dashboard (optional)
    
            
    See what was stopped, across the browser and your coding agent.
    
            
    python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m shadowlens
.venv/bin/python -m shadowlens.native_host install
    
            
    Restart the browser after the last command. The extension's popup then links to the dashboard's Guard screen.
    
          
    
          
    
            3
            
    Claude Code hooks
    
            
    Stops secrets before the model sees them.
    
            
    .venv/bin/python -m shadowlens.hook install
# then, in Claude Code, try a prompt with a fake key
    
            
    Uses ~/.claude/settings.json (or --scope project) and keeps any hooks you already have. uninstall removes only its own.
    
          
    
        
    
      
    
    
    

    
    
    
      
    
        
    Questions
    
        
    What developers ask first.
    
        
    
          
    Does anything I type leave my machine?
    No. The check runs in a WebAssembly module inside the extension, which makes no network requests. You can verify that in the extension's network panel, and the demo above is the same engine running on this page.
    
          
    Will it break the chat?
    It avoids that on purpose: clean messages are never delayed (the composer is checked as you type), and when it does step in it sends or pastes for you the way you would. Chat sites change often; each one has its own adapter, and the end-to-end tests run against editors built like theirs.
    
          
    What about false positives?
    Pick Not a secret in the panel and that exact value (as a keyed fingerprint, never the text) is not flagged again. Low-risk findings like an email address only add a quiet badge.
    
          
    How is this different from enterprise AI-DLP tools?
    Those watch a whole company from the network and report back to an admin. Shadow Lens is for one person at the point of typing: it stops the mistake before it happens, keeps everything local, and costs nothing to run. It is a developer tool and a learning project, not a compliance product.
    
          
    Does it work with Cursor, Copilot or other IDE tools?
    Claude Code is supported through its hooks. The scan command and the git pre-commit check work anywhere. Editors that expose a prompt hook can reuse the same engine; that is the next thing to add.
    
          
    Is it audited?
    No. It is open source (MIT) and heavily tested, and every claim on this page maps to a test or a benchmark you can run. Read it before you trust it.
